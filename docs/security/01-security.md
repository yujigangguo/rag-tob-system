# 安全优化方案

## 术语解释

| 术语 | 解释 |
|------|------|
| **CORS** | 跨域资源共享（Cross-Origin Resource Sharing），控制哪些网站可以访问你的 API |
| **JWT** | JSON Web Token，一种用于身份验证的令牌格式 |
| **SECRET_KEY** | 用于加密 JWT 的密钥，必须保密且足够复杂 |
| **HTTPS** | 加密的 HTTP 协议，防止数据被窃听 |
| **SQL 注入** | 攻击者通过输入恶意 SQL 代码来破坏数据库 |
| **XSS** | 跨站脚本攻击，攻击者在网页中注入恶意脚本 |
| **CSRF** | 跨站请求伪造，诱骗用户执行非本意的操作 |
