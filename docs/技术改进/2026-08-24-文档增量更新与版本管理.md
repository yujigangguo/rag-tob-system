# 技术改进:文档增量更新与版本管理

> 日期:2026-08-24
> 涉及:文档上传/解析链路、检索、前端文档管理
> 对应需求:同名重传应"增量更新"(只处理变化内容),并支持历史版本查看与回滚

---

## 1. 变更概述

原实现中,文档重传(同名覆盖)会**整份重新切分、全部子块重新 embedding**,且产生重复文档记录;
无法区分"文件没变"与"文件改了",也没有版本概念,改版后旧内容不可追溯、不可回滚。

本次引入 **三级能力**:

1. **文件哈希去重** —— 同名且内容一致的重传直接复用,零消耗;
2. **块级内容增量** —— 同名但内容变化时,按子块内容哈希复用未变化向量,只重新嵌入变化部分;
3. **版本管理与回滚** —— 重传生成新版本,旧版本块与向量保留,可查看任意版本、一键回滚。

---

## 2. 新旧功能对比

| 场景 | 旧行为 | 新行为 |
|------|--------|--------|
| 上传同名同内容文件 | 生成**重复文档记录**,doc_count 增加,整份重新解析 | **哈希去重直接复用**,不新增记录、不重新解析、零 embedding 消耗 |
| 上传同名改版文件 | 覆盖为新文档?——实际是新增一条记录;旧记录残留 | 覆盖更新**同一文档记录**;未变化子块**复用旧向量**,只嵌入变化部分 |
| 修改文档中一小段 | 整份重新切分 + **全部子块重新 embedding** | 内容相同的子块**零消耗复用**,仅变化/新增子块嵌入 |
| 历史内容追溯 | 无版本概念,旧内容被覆盖/删除后不可查 | 保留全部历史版本,可查看任意版本的块内容 |
| 回滚 | 不支持 | 一键回滚到上一版本(仅管理员);当前版本独有向量被清理,与其他版本共享的向量保留 |
| 解析失败 | 旧数据已被删,文档 failed,无回退 | **自动回滚**本次新建的行与向量,旧版本数据保持可用 |
| 同名重传后查进度 | 可能读到上一次解析遗留的 `completed`(前端提前显示"解析完成") | 上传时**重置进度**,且仅 `pending` 状态才启动解析 |
| 检索/BM25 | 所有块参与(改版后新旧混杂) | **只使用当前版本子块**,旧版本不污染检索与评测 |

## 4. 数据与接口变化

**表结构(新增列,`scripts/init_rbac.py` 幂等迁移):**

| 表 | 列 | 说明 |
|----|-----|------|
| `documents` | `content_hash` VARCHAR(64) | 文件 SHA-256(去重) |
| `documents` | `version` INT DEFAULT 1 | 当前版本号 |
| `chunks` | `content_hash` VARCHAR(64) | 子块文本哈希(向量复用) |
| `chunks` | `version` INT DEFAULT 1 | 所属文档版本 |

**API 变化:**

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/knowledge-bases/{kb}/documents` | 行为变化:同名去重复用 / 覆盖更新;仅 pending 触发解析 |
| GET | `/api/knowledge-bases/{kb}/documents/{id}` | 响应新增 `version` 字段 |
| GET | `/api/knowledge-bases/{kb}/documents/{id}/versions` | **新增**:版本列表 |
| GET | `/api/knowledge-bases/{kb}/documents/{id}/versions/{v}/chunks` | **新增**:指定版本块列表 |
| POST | `/api/knowledge-bases/{kb}/documents/{id}/rollback` | **新增**:回滚到上一版本(仅管理员) |

## 5. 影响与注意事项

- **兼容性**:老文档 `content_hash`/`version` 为默认值,首次改版重传后即进入增量/版本体系;未改动前行为不变;
- **旧版本向量保留**:所有历史版本的向量一直保留(未做自动清理),文档长期多次改版后 Milvus 会累积旧版本向量——后续可加"保留最近 N 版 + 清理更旧版本";
- **跨版本向量共享**:内容未变的子块跨版本共享同一向量主键,回滚只删除当前版本独有向量,共享向量保留(已处理);
- **块编辑(update_chunk)不产生新版本**:编辑单个父块仍就地重切,不纳入版本管理(有意为之,版本以"文件重传"为单位);
- **回滚不可逆**:回滚会删除当前版本内容,操作前有确认提示。
