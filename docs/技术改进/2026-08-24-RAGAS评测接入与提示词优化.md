# 技术改进:RAGAS 评测接入与提示词优化

> 日期:2026-08-24
> 涉及:评测依赖、评测管线、评测集、提示词
> 对应需求:用 RAGAS 框架评估系统效果,产出评测文档

---

## 1. 变更概述

原系统仅有一套**自研简易指标**(`evaluation/eval_metrics.py`:recall@k + LLM 忠实度判断),
无标准评测框架、无评测集与报告产出。

本次接入 **RAGAS 0.2**(业界标准 RAG 评测框架):

- 新增评测依赖与**评测管线**(真实检索 + 生成链路,与线上一致);
- 新增 **16 条评测集**(覆盖三份测试文档,含数值/流程/故障处理类问题);
- 一键输出 **5 项指标**:Faithfulness / Answer Relevancy / Context Precision / Context Recall / Answer Correctness;
- 依据首轮评测结论优化**提示词**(新增"要点完整"约束),形成可对比的优化前后基线。

---

## 2. 新旧功能对比

| 场景 | 旧行为 | 新行为 |
|------|--------|--------|
| 评测框架 | 自研简易指标(recall@k + LLM 判断) | RAGAS 标准 5 指标(LLM-as-judge + 语义相似度) |
| 评测运行 | 手动脚本,指标单一 | `uv run python evaluation/ragas_eval.py`,自动准备评测库 + 全链路评测 |
| 评测集 | 关键词式样例 | `data/ragas_eval.json`:问题 + 标准答案 + 期望来源 |
| 结果产出 | 无报告 | 控制台汇总 + `docs/ragas_eval_result.json`(每题明细)+ 评测报告 |
| 检索范围追溯 | 无 | 评测链路带真实 `kb_ids`/版本过滤,与线上一致 |
| 提示词 | 简洁风格,未约束要点完整性 | 新增【要点完整】规则(覆盖前提/数值/步骤/例外),流程类先结论后步骤 |
| 优化效果对比 | 无基线 | 首轮评测(平均 0.93)作为**优化前基线**,重跑即可对比 |

## 3. 代码改动点

| 文件 | 改动 |
|------|------|
| `pyproject.toml` / `uv.lock` | dev 依赖新增 `ragas>=0.2.6,<0.3`、`fpdf2`(演示数据用) |
| `evaluation/pipeline.py`(新) | 评测库准备、文档解析、真实检索(含版本过滤)/生成链路 |
| `evaluation/ragas_eval.py`(新) | 评测入口:跑链路 → RAGAS 打分 → 输出 JSON |
| `data/ragas_eval.json`(新) | 16 条评测集(问题 + 标准答案 + 来源) |
| `app/rag/prompts.py` | 系统提示词新增【要点完整】;用户提示词要求覆盖全部要点 |
| `docs/RAGAS评测指南.md` / `RAGAS评测报告.md` | 指标说明、运行方法、首轮结果与改进建议 |

---

## 4. 数据与接口变化

无接口/表结构变化。新增脚本与数据文件:

| 路径 | 说明 |
|------|------|
| `evaluation/ragas_eval.py` | 评测入口(`--dataset` / `--output` / `--limit` / `--kb-name`) |
| `evaluation/pipeline.py` | 评测管线(可复用) |
| `data/ragas_eval.json` | 评测集 |
| `docs/ragas_eval_result.json` | 评测结果(每题答案/上下文/分数) |

---

## 5. 影响与注意事项

- **API 消耗**:评测每问题约 6 次 LLM 调用 + embedding,注意额度;
- **评测口径**:Answer Correctness 由"事实一致性 + 语义相似度"加权,对措辞敏感;对比时保持同一评测集;
- **提示词变更影响线上**:提示词优化后需重建镜像;报告已标注为优化前基线;
- **评测库隔离**:自动创建的"评测知识库"独立于业务库,可复用(已解析文档不重复解析)。

---

## 6. 验证情况

- 首轮评测(16 条):**平均 0.9306** —— Faithfulness/Context Precision/Context Recall 均 1.0,Answer Relevancy 0.799,Answer Correctness 0.854;
- 薄弱项(回答遗漏次要条款、流程类回答过短)已定位到提示词并优化;
- 全量 pytest 通过。
