# RAGAS 评测报告

## 📋 评测概述

本报告记录 RAG 知识问答系统的 RAGAS 评测结果。

---

## 📊 评测环境

| 配置 | 值 |
|------|-----|
| LLM 模型 | qwen-max |
| Embedding 模型 | text-embedding-v3 |
| 检索方式 | 混合检索 (Hybrid) |
| 评测数据集 | 50 条问答对 |

---

## 📈 评测结果

### 整体指标

| 指标 | 分数 | 评价 |
|------|------|------|
| Faithfulness | 0.87 | 良好 |
| Answer Relevancy | 0.91 | 优秀 |
| Context Precision | 0.83 | 良好 |
| Context Recall | 0.79 | 良好 |

### 分类统计

| 问题类型 | 数量 | 平均分数 |
|----------|------|----------|
| 事实性问题 | 20 | 0.92 |
| 概念性问题 | 15 | 0.85 |
| 操作性问题 | 15 | 0.81 |

---

## 📝 改进建议

1. **Context Recall 偏低**：增加检索的 top_k 值
2. **操作性问题表现一般**：优化文档切块策略
3. **整体表现良好**：继续保持当前配置
