# 技术架构

## 📋 系统架构概述

RAG 知识问答系统采用前后端分离架构，基于检索增强生成（RAG）技术实现智能问答。

---

## 🔄 数据流

### 1. 文档上传流程

```
用户上传文档
    │
    ▼
保存文件到本地
    │
    ▼
创建文档记录（status=pending）
    │
    ▼
后台线程异步解析
    │
    ├── 解析文档内容
    ├── 父子分块
    ├── 向量化（Embedding）
    ├── 写入 Milvus
    └── 写入 MySQL（status=completed）
```

### 2. 问答流程

```
用户输入问题
    │
    ▼
选择知识库
    │
    ▼
混合检索
    ├── 稠密向量检索（Milvus）
    └── 稀疏检索（BM25）
    │
    ▼
RRF 融合排序
    │
    ▼
父子分块映射
    │
    ▼
构造提示词
    │
    ▼
调用 LLM（流式输出）
    │
    ▼
返回回答 + 引用
    │
    ▼
保存对话记录
```

## 🔐 权限体系

### 角色定义

| 角色 | 权限范围 |
|------|----------|
| 系统管理员 | 所有功能，包括用户管理、部门管理 |
| 部门管理员 | 管理本部门的知识库和用户 |
| 普通用户 | 使用有权限的知识库进行问答 |

### 权限控制

```
API 请求
    │
    ▼
JWT 验证
    │
    ▼
角色检查
    │
    ▼
部门权限检查
    │
    ▼
返回数据（按权限过滤）
```
