# 使用说明

## 📖 用户操作手册

本指南介绍 RAG 知识问答系统的各项功能和操作方法。

---

## 🔐 登录系统

### 访问地址
- 本地部署：http://localhost:8080
- 服务器部署：http://你的域名或IP

### 登录步骤
1. 打开浏览器访问系统地址
2. 输入用户名和密码
3. 输入验证码
4. 点击"登录"按钮

### 默认账号
| 角色 | 用户名 | 密码 |
|------|--------|------|
| 系统管理员 | admin | admin123 |

> ⚠️ 首次登录后请立即修改密码！

---

## 💬 智能对话

### 开始对话

1. 点击左侧菜单"对话"
2. 点击"新建对话"按钮
3. 选择知识库（可多选）
4. 输入问题
5. 点击"发送"或按 Enter

### 对话界面

```
┌─────────────────────────────────────────────────────────┐
│  会话列表  │           对话区域           │  参数设置  │
│            │                              │            │
│  - 新建    │  用户: 什么是RAG?            │  知识库    │
│  - 对话1   │                              │  - 库1     │
│  - 对话2   │  助手: RAG是...[1]           │  - 库2     │
│            │                              │            │
│            │  ┌─────────────────────┐    │  模型      │
│            │  │ 输入问题...          │    │  温度      │
│            │  └─────────────────────┘    │  Token数   │
└─────────────────────────────────────────────────────────┘
```

### 参数说明

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 知识库 | 选择要检索的知识库 | 根据问题选择 |
| 大模型 | 选择使用的模型 | qwen-max |
| 温度 | 回答的随机性（0-2） | 0.7 |
| Top P | 核采样参数 | 0.8 |
| 最大 Token | 回答的最大长度 | 2048 |
| 历史轮数 | 保留的对话轮数 | 5 |

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Enter | 发送消息 |
| Shift + Enter | 换行 |

### 引用溯源

回答中的 `[1]`、`[2]` 等标记是引用链接：
- 点击可跳转到知识库详情
- 查看引用的原文内容

### 对话导出

1. 鼠标悬停在会话列表中的对话
2. 点击"更多"按钮（三个点）
3. 选择"导出 Markdown"或"导出 JSON"
4. 文件将自动下载

## 📚 知识库管理

### 查看知识库

1. 点击左侧菜单"知识库"
2. 查看所有有权限的知识库
3. 使用搜索框快速查找

### 知识库信息

| 信息 | 说明 |
|------|------|
| 名称 | 知识库名称 |
| 描述 | 知识库简介 |
| 所属部门 | 归属的部门 |
| 检索方式 | 混合检索/稠密检索 |
| 文档数量 | 包含的文档数 |

### 创建知识库（管理员）

1. 点击"创建知识库"
2. 填写信息：
   - 名称：知识库名称
   - 描述：可选
   - 所属部门：选择部门
   - 检索方式：推荐混合检索
   - 切块大小：默认 500
3. 点击"确定"

---

## 📄 文档管理

### 查看文档

1. 点击知识库进入详情
2. 左侧显示文档列表
3. 右侧显示文档块预览

### 上传文档（管理员）

1. 点击"上传文档"
2. 选择文件（支持 PDF、Word、PPT、TXT、Markdown）
3. 设置参数：
   - 切块大小：默认 500
   - 重叠大小：默认 50
4. 点击"上传并解析"
5. 等待解析完成

### 文档预览

1. 在文档列表中点击"预览"
2. 弹窗显示文档内容
3. PDF 文件会在新窗口打开

### 文档版本

1. 点击文档旁的版本号（如 v1）
2. 查看历史版本列表
3. 点击"查看"查看旧版本内容
4. 点击"回滚到上一版本"（管理员）

### 批量删除（管理员）

1. 勾选要删除的文档
2. 点击"删除(N)"按钮
3. 确认删除

## 👤 个人设置

### 修改个人信息

1. 点击右上角头像
2. 选择"个人设置"
3. 修改昵称、邮箱、头像
4. 点击保存

### 修改密码

1. 点击右上角头像
2. 选择"修改密码"
3. 输入旧密码和新密码
4. 点击确认

1. 点击左侧菜单"管理后台"

## ❓ 常见问题

### Q1: 为什么没有检索到相关内容？

1. 检查是否选择了正确的知识库
2. 检查知识库中是否有相关文档
3. 尝试换一种问法

### Q2: 回答质量不好怎么办？

1. 调整温度参数（越低越精确）
2. 增加历史对话轮数
3. 选择更相关的知识库

### Q3: 如何提高检索准确性？

1. 使用混合检索模式
2. 优化文档切块大小
3. 上传高质量的文档

### Q4: 上传文档失败怎么办？

1. 检查文件大小（最大 10MB）
2. 检查文件格式是否支持
3. 检查网络连接
