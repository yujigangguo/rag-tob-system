# 项目说明

## 📖 项目简介

RAG 知识问答系统是一个基于 **检索增强生成（RAG）** 技术的智能问答系统，支持上传文档、构建知识库、并通过大模型进行智能问答。

## 🎯 核心功能

### 1. 知识库管理
- ✅ 创建多个知识库
- ✅ 支持按部门隔离权限
- ✅ 支持公开/私有知识库
- ✅ 知识库搜索功能

### 2. 文档管理
- ✅ 支持多种格式：PDF、Word、PPT、TXT、Markdown
- ✅ 智能分块：父子分块策略
- ✅ 增量更新：版本管理与回滚
- ✅ 在线预览：直接在网页查看文档

### 3. 智能问答
- ✅ 流式输出：逐字显示回答
- ✅ 引用溯源：点击查看原文
- ✅ 多轮对话：保持上下文
- ✅ 对话导出：支持 Markdown 和 JSON

### 4. 混合检索
- ✅ 稠密向量检索：语义相似度
- ✅ 稀疏检索（BM25）：关键词匹配
- ✅ RRF 融合：综合排序

### 5. 权限管理
- ✅ 角色体系：系统管理员、部门管理员、普通用户
- ✅ 部门隔离：不同部门数据隔离
- ✅ 操作审计：记录关键操作

## 🏗️ 技术栈

### 后端
| 技术 | 说明 |
|------|------|
| Python 3.11 | 编程语言 |
| FastAPI | Web 框架 |
| SQLAlchemy | ORM 框架 |
| LangChain | LLM 编排框架 |
| Milvus | 向量数据库 |
| MySQL 8.0 | 关系型数据库 |
| Redis | 缓存 |

### 前端
| 技术 | 说明 |
|------|------|
| Vue 3 | 前端框架 |
| TypeScript | 类型安全 |
| Element Plus | UI 组件库 |
| Vite | 构建工具 |

### AI 模型
| 模型 | 用途 |
|------|------|
| 通义千问 qwen-max | 大语言模型 |
| text-embedding-v3 | 文本向量化 |
