## 🎯 核心功能

### 1. 智能问答
- ✅ 流式输出：逐字显示回答
- ✅ 引用溯源：点击查看原文
- ✅ 多轮对话：保持上下文
- ✅ 参数调节：温度、Top P、Token 数
- ✅ 对话导出：支持 Markdown 和 JSON

### 2. 知识库管理
- ✅ 多知识库支持
- ✅ 部门权限隔离
- ✅ 公开/私有设置
- ✅ 知识库搜索
- ✅ 混合检索/稠密检索

### 3. 文档管理
- ✅ 多格式支持：PDF、Word、PPT、TXT、Markdown
- ✅ 智能分块：父子分块策略
- ✅ 增量更新：版本管理与回滚
- ✅ 在线预览
- ✅ 批量操作

### 4. 用户权限
- ✅ 角色体系：系统管理员、部门管理员、普通用户
- ✅ 部门隔离
- ✅ 操作审计
- ✅ 个人设置

## 🔧 技术特性

### 检索能力
- **稠密向量检索**：基于 Embedding 的语义检索
- **稀疏检索（BM25）**：基于关键词的精确匹配
- **混合检索**：RRF 融合两种检索结果
- **多知识库检索**：跨知识库检索并合并结果

### 性能优化
- **Embedding 缓存**：减少重复 API 调用
- **BM25 索引缓存**：加速检索
- **数据库连接池**：复用连接
- **Gunicorn 多 Worker**：并发处理

### 安全特性
- **JWT 认证**：无状态认证
- **bcrypt 密码哈希**：安全存储
- **图形验证码**：防止暴力破解
- **请求限流**：防止滥用
- **CORS 配置**：跨域控制
